# Explainable Fuzzy Machine Learning for PLGA Drug-Release Prediction

Fuzzy (Low/Medium/High) feature representations applied to drug release from
PLGA long-acting injectable microparticles, evaluated under drug-grouped
cross-validation so that no drug appears in both training and test folds.

## How the pieces fit together

The work runs in four stages. Read them in this order.

**1. Proposal — `proposal.md`**
Research proposal (v2, detailed): problem statement, dataset, the three-layer
methodology (fuzzification → modelling → rule extraction), leakage constraints,
evaluation metrics, and an honest summary of findings so far.

**2. Membership functions — `membership_functions.ipynb`**
Builds the fuzzy layer. Derives leakage-free triangular Low/Medium/High
membership functions from training-fold quantiles only, reproduces the
collaborator's exploratory 8-rule decision tree as the starting point, and
translates its crisp thresholds into fuzzy statements.
Outputs: `membership_knots.csv` (per-fold knot positions),
`membership_functions.png`, `collaborator_rules_fuzzy.png`.

**3a. Classification study — `fuzzy_classification.ipynb` → `FINDINGS.md`**
Compares six arms (crisp / fuzzy-only / hybrid features × hard / soft labels)
on a release-behaviour classification target under `GroupKFold(5)` on exact
Drug SMILES. Tests whether the fuzzy advantage survives boundary perturbation.
Figures: `figures/fig1_arm_comparison.png`, `figures/fig2_boundary_robustness.png`,
`figures/fig3_shap.png`. `FINDINGS.md` holds the written conclusions — every
number in it is generated by the notebook.

**3b. Earlier full study — `run_study.py` → `RESULTS_SUMMARY.md`**
The earlier completed end-to-end study (Tasks A–F): fold construction,
fuzzification diagnostics, crisp vs fuzzy vs hybrid regression and
classification, rule extraction and held-out rule validation, SHAP attribution.
Run with `python run_study.py`; all artifacts land in `study_results/`.

**4. Open questions — `COLLABORATOR_CHECKLIST.md`**
Assumptions still to be confirmed with the team, ordered by how much each would
change the results (the `Time` unit is the highest-impact one).

## Data

321 formulations and 4,913 release measurements. `mp_dataset_processed.xlsx` is
a numeric projection of `mp_dataset_initial.xlsx`; the join is exact. Source:
Bao et al. (2025), *Scientific Data* 12(1), 364.

## Running

The notebooks and `run_study.py` read the two workbooks from the project root
and import from `fuzzypharma/`. Requires `numpy`, `pandas`, `scikit-learn`,
`xgboost`, `shap`, `matplotlib`, `openpyxl`.

## Archive

`archive/` holds superseded and exploratory material kept for reference:
earlier proposal and README versions, exploratory notebooks, the reference
paper PDF, and stale intermediate outputs. Nothing in the list above depends
on it.
